# timesensei.github.io

Privacy policy and support pages for Time Sensei, an iOS timing game.

Twelve languages: `en`, `tr`, `es`, `pt`, `fr`, `de`, `it`, `ru`, `id`, `ja`,
`ko`, `zh`. Each has the same three files:

    /<code>/index.html
    /<code>/privacy.html
    /<code>/support.html

The root forwards to the visitor's own language when it exists here, and
otherwise to English. Adding a language means adding one more `/<code>/`
directory with those three files and listing it in the root.
