The root, [timesensei.github.io](https://timesensei.github.io/), forwards to the visitor's own language
when it exists here and to English otherwise.

Every page lives under a language directory and each directory holds the same
three files, so adding a language means adding one more `/<code>/` with
`index.html`, `privacy.html` and `support.html`, then listing it in the root.
